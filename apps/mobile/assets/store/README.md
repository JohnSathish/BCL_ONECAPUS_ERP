# Store listing assets

| File                  | Purpose                      | Spec                         |
| --------------------- | ---------------------------- | ---------------------------- |
| `feature-graphic.png` | Play feature graphic         | 1024×500 PNG                 |
| `screenshots/`        | Phone screenshots (add here) | Min 2; 1080×1920 recommended |

## Capture screenshots

1. Run a release/internal build on a phone or emulator (1080×1920).
2. Capture at least:
   - Welcome / login
   - Student home dashboard
   - Fees or attendance
   - Notifications center
3. Do not include personal student PII in public listing shots (use demo data).

Upload the same assets in Play Console → Main store listing.
